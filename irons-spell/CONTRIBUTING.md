# Contributing

Anyone can contribute to this project.

You are free to:

- Submit pull requests
- Modify systems
- Rewrite features
- Replace assets
- Create forks
- Publish your own versions

There is no restriction on experimentation or customization.

## Guidelines

- Keep the project open and community-friendly
- Avoid malicious code
- Respect community contributors
- Document major changes when possible

## Philosophy

This project is designed to evolve through community collaboration rather than
central ownership.
